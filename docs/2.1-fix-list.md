# ModiCom 2.1 fix list (temporary)

This is a working document for the 2.1 fix phase. It tracks the
defects exposed by the deterministic test suites in `tests/`. It is
not permanent documentation: when every item below is resolved,
fold a plain-language summary into the 2.1 section of
`docs/history.md` and delete this file.

Working rules:

- The probe result is the truth; this list is only the queue. If
  they disagree, the test wins and the row is corrected.
- Update the row in the same commit as its fix, and promote the
  probe into its suite's green run in that commit so the fix
  becomes a regression test.
- Fix one defect (row) per commit, re-running all green suites
  before committing.
- Probes that already pass (TEDITIO P2-P4, P8; TEDITOPS X1-X3;
  TEDITIN B3) are not defects and are not tracked here.
