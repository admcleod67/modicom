# ModiCom 2.1 editor split (temporary)

This is a working document for splitting `src/EDITOR.C` (~1260 lines)
into smaller translation units. It is not permanent documentation:
when every item below is done, fold a short note into the 2.1 section
of `docs/history.md` and delete this file.

Working rules:

- One module (row) per commit. Re-run all green suites before
  considering that step done. Do not create commits unless the
  maintainer explicitly asks.
- Prefer move-only extractions: no behaviour changes in the same
  commit as a split. If a small fix is required to link or prototype
  cleanly, record it in the Status column.
- The probe/green suites are the truth. If a split breaks a green
  run, fix or revert that step before continuing.
- Update this row’s Status in the same change set as the extraction.

## Design decisions

Recorded so later steps do not reopen them:

| Topic | Decision |
|-------|----------|
| Module set | **Core**, **Status**, **Nav**, **Edit**, **File I/O**, **Search** — matches how the file and test suites are already organised |
| Shared globals | Stay defined in core (`EDITOR.C`): `start`, `ptr`, `end`, `fname`, `x`, `y`, `lineno`, `lcount`, `changed`, `insert`, `maxrow`, `toobig`. Other units `extern` them (via `EDITOR.H` or a small shared internal header if the public header would grow too noisy) |
| Public API | `EDITOR.H` still exports `textedit` (and any globals/prototypes the harnesses need). Module headers declare that module’s functions |
| `prompt` | Lives in **Status** (status-line / top-row UI). **Search** and **File I/O** call it |
| Word motion | **Nav** (`nextword` / `lastword`) |
| `abortedit` | **Edit** (editing-session control; confirms discard) |
| `ctrlkey` / `textedit` | Stay in **Core** |
| Include guards | Every new/changed header uses classic `#ifndef` / `#define` / `#endif` |
| Build | Add each new `.C` to `MODICOM.PRJ` / production make and to `tests/TESTS.MAK` as needed when that module is extracted |

## Target layout

| Unit | Files (proposed) | Responsibilities |
|------|------------------|------------------|
| Core | `EDITOR.C`, `EDITOR.H` | Globals; `textedit` main loop; `ctrlkey` |
| Status | `STATUS.C`, `STATUS.H` | `helpscreen`, `statmsg`, `showstatus`, `showpos`, `scoreboard`, `helptoggle`, `msg`, `prompt` |
| Nav | `NAV.C`, `NAV.H` | `lineup` / `linedown`, `gotocol` / `gotorow`, cursor moves, `pageup` / `pagedown`, `scrollup`, `gotobol` / `gotoeol`, `nextword` / `lastword` |
| Edit | `EDIT.C`, `EDIT.H` | `inschar`, `newline`, `addline`, `backspace`, `del` / `delchar` / `delword`, `tabulate`, `abortedit` |
| File I/O | `FILEIO.C`, `FILEIO.H` | `textread` / `textwrite`, `loadfile`, `readfile` / `writefile` |
| Search | `SEARCH.C`, `SEARCH.H` | `findprompt`, `find` |

Display remains `VIDEO.ASM` / `VIDEO.H`. Keyboard and strings stay as they are.

## Extraction queue

Suggested order keeps the core compilable and prefers extracting
leaves that the green suites already exercise in isolation. Status
is first so `prompt` has a home before File I/O and Search move.

| # | Extract | Primary green coverage | Depends on | Status |
|---|---------|------------------------|------------|--------|
| 1 | Status → `STATUS.C` / `STATUS.H` | `TEDITIN` (via `prompt`); all suites that redraw status | Core globals; `VIDEO.H` / conio as today | Open |
| 2 | Nav → `NAV.C` / `NAV.H` | `TEDITOPS` navigation / paging cases | Core globals; Status (`scoreboard` / `showline` callers as today) | Open |
| 3 | Edit → `EDIT.C` / `EDIT.H` | `TEDITOPS` editing cases | Core globals; Nav (`scrollup`, line helpers); Status | Open |
| 4 | File I/O → `FILEIO.C` / `FILEIO.H` | `TEDITIO` | Core globals; Status (`prompt`, `scoreboard`); strings | Open |
| 5 | Search → `SEARCH.C` / `SEARCH.H` | `TEDITIN` (`findprompt`); Find path in Core | Core globals; Status (`prompt`, `scoreboard`); Nav/Video as `find` does today | Open |
| 6 | Core thin-up | Full green set; production `MODICOM /?` | All of the above linked | Open |

After each row: production rebuild (zero BCC `Warning src` lines),
rebuild affected test objects, run `TSTRINGS`, `TEDITIO`, `TEDITOPS`,
`TEDITIN`, `TVIDEO`, confirm `v2.1m`.
